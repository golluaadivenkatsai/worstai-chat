Install WorstAI App

You can download and install WorstAI directly onto your PC desktop or mobile phone as a standalone app.

💻
On PC (Windows / Mac)
Click the Install icon in your browser address bar (or click ⋮ Menu > Install WorstAI).
📱
On Android Phone
Tap ⋮ (Menu) in Chrome/Edge and tap Install App (or Add to Home screen).
🍏
On iPhone / iPad
In Safari, tap the Share button (⎙), then tap Add to Home Screen.
